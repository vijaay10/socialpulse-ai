## Interpretation notes

- Absolute numbers depend on hardware and on MongoDB and Redis running locally; with MongoDB Atlas over a network, MongoDB latency (and therefore the speed-up) would be higher.
- A cache hit avoids the aggregation but still pays the Redis round trip and JSON parsing, which grows with payload size.
- Cache misses are slightly slower than MongoDB-direct because they add a Redis GET and SET.
